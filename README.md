# Árvore de Links — Nathálya Dev

Minha página de links profissionais. Concentra, em um único endereço, o essencial da minha presença digital para quem chega pelo Instagram e demais redes.

## Objetivo

Apresentar quem sou, o que faço e por onde me encontrar — com hierarquia clara para quem busca contratar desenvolvimento front-end.

## Conteúdo

- Perfil e posicionamento
- CTA para início de projeto
- Link para o portfólio
- Projetos selecionados
- Serviços
- Redes profissionais

## Stack

| Tecnologia | Uso |
| --- | --- |
| HTML5 | Estrutura e conteúdo |
| CSS3 | Layout responsivo, tipografia e identidade visual |

Sem frameworks de UI. Tipografia via Google Fonts (Manrope e DM Serif Display).

## Estrutura

```text
arvore-de-links/
├── index.html          # Página principal
├── styles.css          # Estilos
├── README.md
└── src/
    ├── assets/         # Logo e mídias
    ├── css/
    │   └── reset.css   # Reset e tokens
    └── js/
        └── index.js
```

## Identidade visual

Direção **Editorial Tech Minimal**. Paleta:

| Token | Hex |
| --- | --- |
| Creme | `#F7F3ED` |
| Preto | `#181818` |
| Cinza | `#5C5C5C` |
| Bege | `#DCD5CC` |
| Azul petróleo | `#28545A` |
| Branco | `#FFFFFF` |

O azul petróleo (`#28545A`) é usado em CTAs, links e indicadores de interação.
